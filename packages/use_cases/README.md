# use_cases

Zadržan paket iz početnog workspace-a. Sadrži zajedničku mehaniku KT1 memorijskog
adaptera i demo seed. Svaka aplikacija kreira svoju instancu kroz sopstveni fake repo.
Port ostaje u domenu. Kašnjenje je pre atomarne provere/upisa, revizija štiti prelaze.
Testovi iz root-a: `flutter test packages/use_cases/test`.
